# CodeHub

Aplicación web empresarial para la gestión interna de proyectos, empleados y clientes, con autenticación, control de acceso por rol y generación de reportes en PDF.

- Backend: Java 21 + Spring Boot + PostgreSQL
- Frontend: React + TypeScript + Vite

## Usuarios para ingresar

El sistema genera automaticamente los siguientes suarios:

- Usuario: admin / Contraseña: admin123 — Rol: ADMIN
- Usuario: gerente / Contraseña: gerente123 — Rol: GERENTE
- Usuario: empleado / Contraseña: empleado123 — Rol: EMPLEADO
